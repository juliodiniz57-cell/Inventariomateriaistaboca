ATUALIZAÇÃO INVENTÁRIO TABOCA V3

1) SUPABASE - executar uma única vez:
   - Abra o arquivo ATUALIZACAO_CADASTROS_DINAMICOS.sql
   - Copie todo o conteúdo
   - Supabase > Editor SQL > Nova consulta > Cole > Correr

2) GITHUB - substituir/enviar:
   - index.html
   - app.js
   - styles.css
   - logo-taboca.png

3) NÃO ALTERAR:
   - config.js

4) Depois do GitHub Pages atualizar:
   - Abra o site
   - Pressione Ctrl + F5
